## LLM-generated priors for reinforcement learning

Deep reinforcement learning can require substantial interaction before useful behavior emerges. My M.Sc. thesis investigates whether qualitative knowledge generated by large language models can improve sample efficiency in continuous-control tasks. A central question is how agents can benefit from imperfect prior knowledge while recognizing when that guidance is unreliable.

I developed a pipeline that converts structured task descriptions into fuzzy rule-based controllers implemented in PyTorch. An approximate Bayesian critic using MC dropout guides arbitration between actions proposed by these controllers and a learned DRL neural policy. The language model generates the priors before training, so no LLM calls are required during interaction with the environment.

I evaluate the approach through multi-seed experiments, controlled ablations, and statistical analysis on MuJoCo and Meta-World tasks. Results so far indicate that improvements depend on both the environment and the generated prior: informative guidance can help learning, while mismatched guidance can hinder it. These findings motivate further investigation into how agents assess prior knowledge and the limits of uncertainty-aware arbitration.
