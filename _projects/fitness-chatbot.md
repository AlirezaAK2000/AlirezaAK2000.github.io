**Independent open-source project**

I developed a conversational assistant that generates workout and diet plans using retrieval-augmented generation and reranking, with tool use and dialogue state managed through LangGraph.

I evaluated the system with pairwise comparisons using an LLM judge across relevance, completeness, safety/evidence, and clarity.

**Tools and methods:** LangGraph, RAG, reranking, conversational agents, pairwise evaluation.
