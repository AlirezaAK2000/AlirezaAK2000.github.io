ow can reinforcement learning agents benefit from imperfect knowledge generated by a language model?

This project converts language-model guidance into executable fuzzy control policies and investigates when an agent should follow these priors or rely on its learned policy. Priors are generated before training, so no language-model calls are required during environment interaction.

### Approach

- Built a LangGraph pipeline that generates structured fuzzy rules from task, state, and action descriptions.
- Implemented zero-order Takagi–Sugeno–Kang fuzzy inference in PyTorch.
- Integrated multiple fixed fuzzy policies with TD3 through an auxiliary critic using MC dropout to support uncertainty-aware action arbitration.
- Evaluated the approach on MuJoCo and Meta-World tasks through multi-seed experiments, controlled ablations, and statistical analysis.

Results suggest that the benefits depend on both the task and the generated prior. Informative guidance can improve learning, while mismatched guidance can hinder it. The ongoing research examines when uncertainty-aware arbitration can distinguish useful guidance from unreliable priors.
